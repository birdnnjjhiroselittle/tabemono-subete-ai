# たべものすべてAI

**家の冷蔵庫から、町・国・世界まで。食べものの「ある・ほしい・余る」をすべてつなぐ。**
**しかも、誰も損をしない（パレート改善）。健康も守る。役所に頼らず、下からつなぐ。**

食品ロスを減らし、一人ひとりの健康も良くするためのシステム構想です。家庭・お店・農家・町をつなぎます。

> 状態：構想・企画段階（2026-11）。コードはまだありません。

## 👀 約束：見るだけ・教えるだけ

**画像・映像は、保存しない・送らない・公開しない。**
カメラが見たものはその場で「牛乳 1本 期限11/8」のような文字の情報に変えて、すぐに消します。
返すのは **食べものが無駄にならない・おいしい・健康に良い** ひとことのアドバイスだけです。

> 🎧「今日はキャベツと豚肉で回鍋肉がおすすめ。キャベツを使い切れて、野菜もとれます」

一人ひとりに個人の最適解を教えます。それを積み重ね、誰の分か分からない合計数という薄い信号だけを共有して、**町・国・世界全体の食べものの最適解** へ近づけます。

👉 くわしくは [docs/privacy.md](docs/privacy.md)

## なにをするの？

| 単位 | たべものすべてAIがすること |
|---|---|
| **家庭** | 家にある食材と賞味期限をAIが把握し、食べたい気持ち・家族の好み・予定・**健康**も考えて、使い切る献立と買い物リストを作る |
| **スーパーで** | カメラ付きイヤホン・ARグラスで「牛乳は家にまだ1本、期限はあさってです」と声で教える |
| **町** | 家庭の「来週買う予定」を、個人が分からない形でまとめてお店に伝え、作りすぎを防ぐ。余りは住民 → 子ども食堂 → 堆肥の順に回す |
| **国・世界** | 地域ごとの需要の見通しを農家・メーカー・物流に伝え、作りすぎとムダな輸送を減らす |

## 在庫の把握のしかた

家の中を全部撮り続けなくても在庫は分かります。

```
家の在庫 ＝ 買ったもの − 使ったもの − 捨てたもの
```

| タイミング | 測り方（センシング） |
|---|---|
| 買う | ウェアラブルカメラ／レシート／ネット通販の履歴 |
| しまう | 冷蔵庫の扉を開けたときの撮影、重さを測るマット |
| 使う | 「卵2個使った」の声、調理中の映像 |
| 捨てる | ゴミ箱のカメラ・はかり |

## なぜ食品ロスは減らないのか

日本の食品ロスは年に約460万トン台です。お店などから出る分と家庭から出る分がほぼ半々です（※最新の統計値は要確認）。

根っこにあるのは **「必要な量が事前に分からない」という情報の問題** です。

- 家庭：家に何があるか忘れる、期限に気づかない、買いすぎる
- お店：明日のお客さんの数が分からない → 売り切れを避けるため多めに仕入れる

たべものすべてAIは、**家庭の「来週買う予定」をお店の需要予測につなげる** ことで、この情報の問題を解決します。

⚠️ 余りを安く売るツール **だけ** だと、お店が「余っても売れるから」と仕入れを増やし、ロスが減らないおそれがあります。だから **予測で余りそのものを減らすこと** を中心に置きます。

## 📈 経済学から見ると：なぜ全世界が得をしうるのか

| 考え方 | 意味 |
|---|---|
| **死荷重** | 食品ロスは、作る費用だけかかって誰の満足にもならなかった「消えた価値」。取り戻せば分け合える |
| **新聞売り子モデル** | お店の売れ残りは、予測のばらつき $\sigma$ に比例する。家庭の「来週買う予定」で $\sigma$ を下げれば、廃棄が減る |
| **ブルウィップ効果** | 買う前の需要を川上まで共有すれば、農家の作りすぎまで減る |
| **ハイエク** | 散らばった知識を、中央計画なしでまとめる信号（値段＋誰の分か分からない合計数） |
| **コース** | 取引の手間がほぼゼロになれば、政府なしでも当事者どうしで解決できる |
| **オルソン** | 人は世界のためではなく、自分の便利さのために使う。その結果、世界のロスが減る |
| **オストロム** | 地域の人たちが自分たちのルールで共有資源を管理できる（自律分散の裏づけ） |
| **セン** | 世界規模では損をする人（途上国の小さな農家）もいる。だから得をその人たちにも回す |

> ⚠️ 余りを安く売るだけのツールは、お店の仕入れを増やしてしまう（$\partial q^*/\partial s > 0$）。だから **余りを売るより、予測で余りを減らすことを中心に置く**。

> **食品ロスは、人類がテーブルの上に置き忘れている巨大な取り分である。**

## 🤝 パレート改善：誰も損をしない設計

目標は「社会全体の食品ロスを減らす」こと（功利主義的な目標）です。
ただし、**誰かに損を押しつけて全体の得を増やす方法はとりません**。

> **パレート改善** ＝ 誰の状態も悪くせずに、少なくとも1人の状態を良くする変化

### 食品ロスは「捨てられている得」
お金と手間をかけて作ったのに捨てられている分を減らせば、浮いたお金・食べもの・時間を参加者で分け合えます。

### 関係者ごとのチェック
| 関係者 | 得 | 損が出る可能性 | 損をなくす仕組み |
|---|---|---|---|
| 家庭 | 食費・手間・迷いが減る | 我慢の押しつけ、プライバシー | 提案するだけで強制しない、同意制、映像を保存しない |
| お店 | 廃棄費用が減る、利益が増える | 定価の商品が売れにくくなる | 値引きは閉店前・数量限定、売上ではなく利益で評価 |
| 農家 | 規格外品が売れる | 買いたたかれる | 需要の見通しを農家にも公開、最低価格のルール |
| メーカー | 返品・在庫廃棄が減る | 出荷量が減る | 利益で評価、データ提供で新しい収入 |
| ゴミ処理業者 | — | 処理量が減る | 堆肥化・回収ルートを新しい仕事として委託 |
| 自治体 | ゴミ処理費が減る | 運営費がかかる | 削減できた処理費の一部で運営（成果に応じて払う） |

### 得を分け合う仕組み
```
食品ロスが減って浮いたお金（自治体・お店・メーカー）
        ↓ 一部を出し合う
   たべものすべて基金（仮）
        ↓
住民の地域ポイント／定価の売上が減ったお店／仕事が減った業者
```

### 約束
> **自分で選んで参加した人は、誰も損をしない。参加していない人も、今より悪くはならない。**

- 参加は自分で選ぶ（オプトイン）。AIの提案に従わせない。
- 段階ごとに関係者ごとの得と損を測り、**損をしている関係者が1つでもあれば、次の段階に進む前に設計を直す**。

## 🩺 健康：食品ロスと健康を同時に良くする

アレルギー・持病の制限・体重や血圧・歩数・健診の結果をもとに、献立を調整します。

```
① 安全（アレルギー・食中毒） > ② 健康 > ③ 好み > ④ 食品ロス > ⑤ 食費
```

> **健康を悪くしてまで食品ロスを減らさない。**

さらに、「町の人に足りない栄養」を個人が分からない形でまとめ、地元の農家・お店が作るもの・仕入れるものを変えます。
健康は厚生労働省、農業は農林水産省、食品ロスは消費者庁と役所をまたぎますが、その調整を待たずに **住民・農家・お店が直接つながって** 実現します。
診断はしません。病歴は特に慎重に扱います。

## 🌱 自律分散：役所に頼らず、下からつなぐ

国が上から管理するのではなく、**自分で選んで参加し、助け合い、対等につながる** 仕組みにします（無政府主義＝アナキズムの「自発的な協力と相互扶助」の考え方）。

| 原則 | 内容 |
|---|---|
| データは本人のもの | 端末の中に置く。集めずに学ぶ（連合学習） |
| 参加は自由 | 強制しない。いつでもやめてデータを消せる |
| 相互扶助 | 余りは近所で分け合う、共同購入 |
| 協同組合で運営 | 住民・お店・農家が持ち主。1人1票でルールを決める |
| 町と町は対等に連合 | 中央のサーバーなし。町どうしが横につながり、国・世界へ広がる |

行政は「頼る相手」ではなく「参加者の一人」です。自律分散でも、食品衛生・個人情報・医療に関わる法律は守ります。

👉 くわしくは [docs/decentralized.md](docs/decentralized.md)

## 進め方

| 段階 | 内容 |
|---|---|
| 0. 準備 | 自治体・商工会と話す、今どれだけ捨てているか測る |
| 1. スマホ版＋小さな実証 | レシート・冷蔵庫の写真 → 在庫と献立。お店の余りをLINEで通知 |
| 2. 予測の導入 | 「来週買う予定」をまとめてお店に提案。値下げの自動化 |
| 3. ウェアラブル対応 | カメラ付きイヤホン・ARグラスでスーパーモード、冷蔵庫センサー |
| 4. 町全体〜国へ | 地域ポイント・堆肥化とつなぐ、近くの町へ広げる |

## プライバシー

- **画像・映像は保存しない・送らない・公開しない。** 端末の中で文字の情報に変えたら、すぐに消す。
- 食品以外（店内のほかのお客さんなど）は認識しない。
- データは本人の同意制。家族それぞれがオン・オフを選べる。
- 町どうしで共有するのは、個人が分からない形にまとめた数字だけ。
- 病歴などの健康情報は端末の外に出さない。
- オープンソースなので、本当に集めていないか誰でも確かめられる。

## 🌍 個人最適から世界最適へ

1. 一人ひとりが「無駄にならない・おいしい・健康に良い」食べ方をすると、家庭のロス・お店の売れ残り・医療費が減る。
2. ただし、全員に「今日は鮭」と勧めると鮭が足りなくなる。個人の最適を足しただけでは、全体の最適にならないこともある。
3. そこで、**誰の分か分からない町全体の合計数** だけを共有する。「鮭は予定が多いので、ほうれん草と卵の料理もおいしいですよ」のように、AIどうしが自然に調整する。
4. 中央で計画しなくても、一人ひとりの最適と薄い信号の組み合わせで、町・国・世界へ広がる（ハイエクの「値段は、みんなの知識をまとめる信号」と同じ考え方）。
