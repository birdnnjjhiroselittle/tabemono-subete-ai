# たべものすべてAI

**家の冷蔵庫から、町・国・世界まで。食べものの「ある・ほしい・余る」をすべてつなぐ。**
**しかも、誰も損をしない（パレート改善）。**

食品ロスを減らすためのシステム構想です。家庭・お店・町をつなぎます。

> 状態：構想・企画段階（2026-11）。コードはまだありません。

---

## なにをするの？

| 単位 | たべものすべてAIがすること |
|---|---|
| **家庭** | 家にある食材と賞味期限をAIが把握し、食べたい気持ち・家族の好み・予定も考えて、使い切る献立と買い物リストを作る |
| **スーパーで** | カメラ付きイヤホン・ARグラスで「牛乳は家にまだ1本、期限はあさってです」と声で教える |
| **町** | 家庭の「来週買う予定」を、個人が分からない形でまとめてお店に伝え、作りすぎを防ぐ。余りは住民 → 子ども食堂 → 堆肥の順に回す |
| **国・世界** | 地域ごとの需要の見通しを農家・メーカー・物流に伝え、作りすぎとムダな輸送を減らす |

## 在庫の把握のしかた

家の中を全部撮り続けなくても在庫は分かります。

```
家の在庫 ＝ 買ったもの − 使ったもの − 捨てたもの
```

| タイミング | 測り方（センシング） |
|---|---|
| 買う | ウェアラブルカメラ／レシート／ネット通販の履歴 |
| しまう | 冷蔵庫の扉を開けたときの撮影、重さを測るマット |
| 使う | 「卵2個使った」の声、調理中の映像 |
| 捨てる | ゴミ箱のカメラ・はかり |

## なぜ食品ロスは減らないのか

日本の食品ロスは年に約460万トン台です。お店などから出る分と家庭から出る分がほぼ半々です（※最新の統計値は要確認）。

根っこにあるのは **「必要な量が事前に分からない」という情報の問題** です。

- 家庭：家に何があるか忘れる、期限に気づかない、買いすぎる
- お店：明日のお客さんの数が分からない → 売り切れを避けるため多めに仕入れる

たべものすべてAIは、**家庭の「来週買う予定」をお店の需要予測につなげる** ことで、この情報の問題を解決します。

⚠️ 余りを安く売るツール **だけ** だと、お店が「余っても売れるから」と仕入れを増やし、ロスが減らないおそれがあります。だから **予測で余りそのものを減らすこと** を中心に置きます。

## 🤝 パレート改善：誰も損をしない設計

目標は「社会全体の食品ロスを減らす」こと（功利主義的な目標）です。
ただし、**誰かに損を押しつけて全体の得を増やす方法はとりません**。

> **パレート改善** ＝ 誰の状態も悪くせずに、少なくとも1人の状態を良くする変化

### 食品ロスは「捨てられている得」
お金と手間をかけて作ったのに捨てられている分を減らせば、浮いたお金・食べもの・時間を参加者で分け合えます。

### 関係者ごとのチェック
| 関係者 | 得 | 損が出る可能性 | 損をなくす仕組み |
|---|---|---|---|
| 家庭 | 食費・手間・迷いが減る | 我慢の押しつけ、プライバシー | 提案するだけで強制しない、同意制、映像を保存しない |
| お店 | 廃棄費用が減る、利益が増える | 定価の商品が売れにくくなる | 値引きは閉店前・数量限定、売上ではなく利益で評価 |
| 農家 | 規格外品が売れる | 買いたたかれる | 需要の見通しを農家にも公開、最低価格のルール |
| メーカー | 返品・在庫廃棄が減る | 出荷量が減る | 利益で評価、データ提供で新しい収入 |
| ゴミ処理業者 | — | 処理量が減る | 堆肥化・回収ルートを新しい仕事として委託 |
| 自治体 | ゴミ処理費が減る | 運営費がかかる | 削減できた処理費の一部で運営（成果に応じて払う） |

### 得を分け合う仕組み
```
食品ロスが減って浮いたお金（自治体・お店・メーカー）
        ↓ 一部を出し合う
   たべものすべて基金（仮）
        ↓
住民の地域ポイント／定価の売上が減ったお店／仕事が減った業者
```

### 約束
> **自分で選んで参加した人は、誰も損をしない。参加していない人も、今より悪くはならない。**

- 参加は自分で選ぶ（オプトイン）。AIの提案に従わせない。
- 段階ごとに関係者ごとの得と損を測り、**損をしている関係者が1つでもあれば、次の段階に進む前に設計を直す**。

👉 くわしくは [docs/pareto.md](docs/pareto.md)

## 進め方

| 段階 | 内容 |
|---|---|
| 0. 準備 | 自治体・商工会と話す、今どれだけ捨てているか測る |
| 1. スマホ版＋小さな実証 | レシート・冷蔵庫の写真 → 在庫と献立。お店の余りをLINEで通知 |
| 2. 予測の導入 | 「来週買う予定」をまとめてお店に提案。値下げの自動化 |
| 3. ウェアラブル対応 | カメラ付きイヤホン・ARグラスでスーパーモード、冷蔵庫センサー |
| 4. 町全体〜国へ | 地域ポイント・堆肥化とつなぐ、近くの町へ広げる |

## プライバシー

- 処理はできるだけ端末の中で行い、映像は保存しない。
- 店内で映った人の顔は自動でぼかす。
- データは本人の同意制。家族それぞれがオン・オフを選べる。
- 町や国に渡すのは、個人が分からない形にまとめた数字だけ。
