# 自律分散の運営：行政に頼らず、下からつなぐ

たべものすべてAIは、**国や役所が上から管理する仕組みにはしません**。
一人ひとり・家族・町の人どうしが **自分で選んで参加し、助け合い、対等につながる** 仕組みにします。
政治思想でいえば **無政府主義（アナキズム）** の考え方に近い形です。ここでのアナキズムは「混乱」ではなく、**自発的な協力と相互扶助で社会を回す** という意味です（クロポトキンの『相互扶助論』など）。

---

## 1. なぜ自律分散なのか

| 上から管理する場合 | 自律分散の場合 |
|---|---|
| 役所の縦割り（厚生労働省・農林水産省・消費者庁・環境省）の調整を待つ | 住民・農家・お店が直接つながるので待たなくていい |
| 1か所にデータが集まり、監視の心配がある | データは本人が持つので、監視されにくい |
| 予算や担当者が変わると止まる | 参加者がいる限り続く |
| 全国一律のルール | 町ごとに合ったルールを自分たちで決める |

---

## 2. 5つの原則

### ① データは本人のもの
- 在庫・食事・健康のデータは **自分の端末の中に置く**（ローカルファースト）。
- 外に出すのは、本人が「出してよい」と選んだものだけ。出すときも、個人が分からない形にまとめた数字にする。
- **連合学習** を使う：生のデータを集めなくても、各端末で学んだ結果だけを持ち寄ってAIを賢くできる。

### ② 参加は自由（オプトイン）
- 誰にも参加を強制しない。いつでもやめられて、自分のデータを消せる。
- これは [パレート改善](pareto.md) の約束（自分で選んだ人は誰も損をしない）と同じ考え方です。

### ③ 相互扶助：余りは近所で分け合う
- 余った食材を近所どうしで分ける、まとめて買う（共同購入）、子ども食堂に回す。
- お金だけでなく、「ありがとう」や地域ポイントで回す。

### ④ 協同組合で運営する
- 運営するのは国でも大企業でもなく、**参加者が持ち主の協同組合（データ協同組合）**。
- 住民・お店・農家が組合員になり、**1人1票** で使い方やルールを決める。
- 浮いたお金（[たべものすべて基金](pareto.md)）の分け方も、組合員で決める。

### ⑤ 町と町は対等につながる（連合）
- 「国が全国を統括する」のではなく、**町どうしが対等につながる**（連合）。
- ある町の余りを隣の町の足りないところへ。同じ仕組みで、国・世界へも横に広がる。

```
     上から管理               自律分散（連合）
        国                  町A ─── 町B
       ／＼                  │ ╲   ╱ │
    県    県                 │   ╳   │
   ／＼   ／＼                │ ╱   ╲ │
  町 町  町 町               町C ─── 町D
                       （それぞれの町の中も、家庭・お店・農家が対等につながる）
```

## 3. 技術での実現

| 原則 | 使う技術 |
|---|---|
| データは本人のもの | 端末の中で動くAI、暗号化、本人が管理するデータ保管 |
| 集めずに学ぶ | 連合学習、差分プライバシー（個人が特定されないよう統計にノイズを加える） |
| 誰でも使える | **オープンソース（MITライセンス）**、仕様の公開。どの町でもそのまま使える |
| 町どうしの連合 | 共通のデータ形式で、町ごとのサーバーどうしがつながる（中央のサーバーなし） |
| 公開データの活用 | 日本人の食事摂取基準・食品成分表・気象データなど、許可を待たずに使える公開データ |

## 4. お金の回し方（行政の予算に頼らない）

| 収入 | 内容 |
|---|---|
| 協同組合の会費 | 少額・任意。使う機能に応じて |
| お店・農家の利用料 | 需要の見通しで得をした分の一部 |
| たべものすべて基金 | 食品ロスが減って浮いたお金の一部を出し合う |
| 寄付・クラウドファンディング | 共感してくれる人から |

行政とは **「頼る相手」ではなく「参加者の一人」** としてつきあいます。ゴミ処理費が減った分を基金に入れてくれる自治体があれば歓迎します。

---

## 5. 正直な限界と守ること

- **自律分散 ＝ 法律を守らない、ではありません。** 食品衛生、個人情報（特に病歴）、医療に関わる法律は守ります（→ [健康](health.md)）。
- ゴミの収集・処理は市町村の仕事なので、そこは協力が必要になります。
- 1人1票の話し合いは時間がかかります。最初は小さな町・小さなグループから始めます。
- 誰もが使いこなせるとは限りません。高齢者などには、電話・LINE・近所の人の手助けで参加できるようにします（「もしもしAI」とつなぐ案）。
