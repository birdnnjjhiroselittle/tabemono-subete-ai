## 1. 問題の大きさ：人類にとっての食品問題

| 指標 | 規模（公開推計、※要確認） |
|---|---|
| 世界の食品廃棄（小売・外食・家庭） | 年に約10億トン（消費者が手にできる食べものの約2割）。そのうち約6割が家庭 |
| 収穫から小売までの損失 | 生産された食べものの約13〜14% |
| 世界の飢餓人口 | 約7億人前後 |
| 食品ロス・廃棄による温室効果ガス | 世界の排出量の約8〜10% |
| 日本の食品ロス | 年に約460万トン台（事業系と家庭系がほぼ半々） |

ここから分かる、人類の食品問題の **最大の矛盾** はこれです。

> **食べものは「足りない」のではなく、「必要なところに、必要な量だけ届いていない」。**

捨てられている食べものの量は、飢えている人を養える量を大きく上回ると考えられています。
つまり食品問題の大部分は **生産の問題ではなく、情報と配分の問題** です。経済学はまさに「限られた資源をどう配分するか」を扱う学問なので、この問題に正面から使えます。

## 2. 厚生経済学：食品ロスは「死荷重」である

### 2-1. 社会的余剰
経済全体の豊かさは、次の合計で測られます。

$$
\text{社会的余剰} = \text{消費者余剰} + \text{生産者余剰} - \text{外部費用}
$$

- **消費者余剰**：払ってもいいと思う値段 − 実際に払った値段
- **生産者余剰**：売れた値段 − 作るのにかかった費用
- **外部費用**：取引した人以外が負う費用（ゴミ処理の税金、温室効果ガスなど）

### 2-2. 捨てられた食べものの意味
捨てられた食べものは、**作る費用（土地・水・肥料・労働・エネルギー・輸送）は全部かかっているのに、誰の満足にもならなかった** ものです。
さらに捨てるための処理費と温室効果ガスという **外部費用まで追加** されます。

$$
\text{食品ロスによる損失} = \underbrace{\text{生産・流通の費用}}_{\text{満足を生まなかった}} + \underbrace{\text{処理費} + \text{環境の費用}}_{\text{追加の外部費用}}
$$

これは経済学でいう **死荷重（デッドウェイト・ロス）**、つまり「誰の得にもならずに消えた価値」です。

### 2-3. だからパレート改善が作れる
死荷重があるということは、**誰も損をさせずに誰かを得させる余地（パレート改善の余地）がある** ということです。
食品ロスを減らすことは、消えていた価値を取り戻すことです。取り戻した価値を参加者で分ければ、全員が得をします（→ [パレート改善の設計](pareto.md)）。

> **食品ロスとは、社会がテーブルの上に置き忘れている、巨大な「取り分」である。**

## 3. 在庫理論：新聞売り子モデルと「情報が廃棄を減らす」証明

### 3-1. モデル
お店が明日の分を $q$ 個仕入れるとします。需要 $D$ は前もって分かりません。

- 売値 $p$、仕入れ値 $c$、売れ残りを処分したときに戻る値 $s$（値引き・寄付・飼料など。$s < c < p$）
- **1個足りなかったときの損**：$C_u = p - c$（逃した利益）
- **1個余ったときの損**：$C_o = c - s$

お店にとって一番得な仕入れ量 $q^*$ は、次の式で決まります（**臨界比率**）。

$$
F(q^*) = \frac{C_u}{C_u + C_o} = \frac{p-c}{p-s}
$$

$F$ は需要の累積分布です。たとえば $p=300,\ c=100,\ s=0$ 円なら臨界比率は $\tfrac{200}{300}\approx 0.67$。お店は **「3回に2回は売り切れない量」を仕入れるのが一番得** になり、残りはロスになります。

### 3-2. 予測の誤差が廃棄を生む
需要を平均 $\mu$、ばらつき（標準偏差）$\sigma$ の正規分布と考えると、

$$
q^* = \mu + z\,\sigma, \qquad z = \Phi^{-1}\!\left(\frac{C_u}{C_u+C_o}\right)
$$

そして **売れ残りの期待値** は次のようになります（$\phi$ は標準正規分布の密度、$\Phi$ は累積分布）。

$$
\mathbb{E}[\text{売れ残り}] = \mathbb{E}[(q^* - D)^+] = \sigma\,\bigl[\,\phi(z) + z\,\Phi(z)\,\bigr]
$$

この式の大事なところは、**売れ残りが $\sigma$（予測のばらつき）に比例する** ことです。

> **定理（この企画の土台）**：お客さんにとっての品切れにくさ（サービス水準）を変えずに、予測のばらつき $\sigma$ を半分にできれば、**廃棄も半分になる**。

| 臨界比率 | $z$ | 売れ残りの期待値 |
|---|---|---|
| 0.50 | 0.00 | $0.40\,\sigma$ |
| 0.67 | 0.43 | $0.65\,\sigma$ |
| 0.80 | 0.84 | $0.95\,\sigma$ |
| 0.90 | 1.28 | $1.33\,\sigma$ |

品切れを嫌うお店ほど廃棄が増えます。それでも $\sigma$ を小さくすれば、どのお店でも廃棄は減ります。

### 3-3. 家庭の「来週買う予定」は $\sigma$ を下げる
たべものすべてAIの利用者が、来週買う予定を（誰の分か分からない形で）共有したとします。お店にとっては、**需要の一部が前もって分かっている** 状態になります。

需要を「予定が分かっている部分 $D_k$」と「分からない部分 $D_u$」に分けると、

$$
\sigma^2_{\text{残り}} = \operatorname{Var}(D_u) \quad (\le \operatorname{Var}(D))
$$

利用者の割合を $\alpha$ とし、分からない部分のばらつきもそれに比例して減ると考えると、おおよそ

$$
\sigma_{\text{残り}} \approx \sqrt{1-\alpha}\;\sigma
$$

| 利用者の割合 $\alpha$ | 残りのばらつき | 廃棄の目安 |
|---|---|---|
| 0% | $1.00\,\sigma$ | 100% |
| 20% | $0.89\,\sigma$ | 約89% |
| 50% | $0.71\,\sigma$ | 約71% |
| 80% | $0.45\,\sigma$ | 約45% |

（※単純化したモデル。予定どおりに買わない人もいるので、実際の効果は実証で測る必要があります）

### 3-4. 「余りを売るアプリ」の逆効果を数式で見る
臨界比率 $\frac{p-c}{p-s}$ を見てください。余りを安く売れるアプリが普及して $s$（処分したときに戻る値）が上がると、**臨界比率が上がり、お店はもっと多く仕入れる** ようになります。

$$
\frac{\partial q^*}{\partial s} > 0
$$

例：$s$ が 0円 → 50円になると、臨界比率は 0.67 → 0.80。$z$ は 0.43 → 0.84 になり、**売れ残りの期待値は 0.65σ → 0.95σ と約1.5倍** になります。
値引きアプリでは、値引きで売れた分はロスにならずに済みます。それでも、**仕入れそのものが増える** ので、全体のロスが減るとは限りません。

> だから、たべものすべてAIは **$s$ を上げること（余りを売る）より、$\sigma$ を下げること（予測）を中心に置く**。

### 3-5. まとめると効く：リスクの共有
お店が $n$ 軒あり、それぞれの需要がばらばら（独立）に動くとき、町全体の合計で見ると、ばらつきは $\sqrt{n}$ 分の1になります。

$$
\frac{\sigma_{\text{合計}}}{\mu_{\text{合計}}} = \frac{\sqrt{n}\,\sigma}{n\,\mu} = \frac{1}{\sqrt{n}}\cdot\frac{\sigma}{\mu}
$$

1軒ずつでは読めない需要も、町全体では読みやすくなります。**余りを町の中で融通し合う** のは、このリスクの共有（リスク・プーリング）を使うことです。

## 4. ブルウィップ効果：川上ほどムダが大きくなる

**ブルウィップ効果**（牛追いムチ効果）とは、家庭 → お店 → 問屋 → メーカー → 農家と川上に行くほど、注文のばらつきが大きくなる現象です（フォレスター、リーらの研究）。

原因は次の4つです。
1. それぞれが、自分の受けた注文から需要を予測し直す
2. まとめて注文する（発注の単位が大きい）
3. 値引きセールで、買いだめと買い控えが起きる
4. 品切れを恐れて多めに注文する（取り合い）

結果として、**家庭のちょっとした変化が、農家では大きな作りすぎ・作り足りなさになります**。規格外品の廃棄や、豊作のときの畑での廃棄（いわゆる「すき込み」）もここから生まれます。

**解決策として知られているのは、一番川下の本当の需要を、川上のみんなで共有すること** です。
たべものすべてAIの「来週買う予定」は、レジの売上データよりさらに川下、**買う前の需要** です。これを川上まで共有できれば、ブルウィップ効果の根っこを断てます。

## 5. 情報の経済学：ハイエクとアカロフ

### 5-1. ハイエク：知識は散らばっている
ハイエクは「社会における知識の利用」（1945年）で次のように述べました。経済に必要な知識は、**一人ひとりの頭の中に散らばっている**（「今日は何が食べたいか」「冷蔵庫に何が残っているか」）。それを中央の計画者が全部集めることはできない。そして **値段** は、散らばった知識を一つの信号にまとめる仕組みである、と。

- 中央計画（国が全部決める）→ 知識を集めきれないので失敗する
- 市場の値段 → 情報をまとめられるが、**値段が変わるのが遅すぎる**（食べものは数日で傷む）

たべものすべてAIは、値段だけでなく **「誰の分か分からない合計数」という、もう一つの信号** を加えます。

$$
\text{信号} = \bigl(\text{値段},\ \textstyle\sum_i \text{予定}_i\bigr)
$$

中央計画でも、値段だけの市場でもない **第3の道**。分散したまま、速く調整できます（→ [見るだけ・教えるだけ](privacy.md)、[自律分散の運営](decentralized.md)）。

### 5-2. アカロフ：期限が近い食品の「レモン市場」
アカロフの「レモン市場」（1970年）は、**売り手は品質を知っているのに、買い手は知らない（情報の非対称性）** と、良い品まで市場から消えてしまうことを示しました。

期限が近い食品はまさにこれです。
- 買い手：「本当に大丈夫？傷んでない？」と不安 → 安くても買わない
- 結果：まだ十分おいしい食品まで捨てられる

たべものすべてAIは、
- 「この食品は、あなたの家の今の在庫なら、明日の夕食で使い切れます」
- 「保存の状態と期限から見て、今日・明日なら安心して食べられます」

と、**その人にとっての価値と安全を教える** ことで、情報の非対称性を小さくします。これは経済学でいう **シグナリング**（信頼できる情報を相手に伝えること）の役割です。

## 6. 外部性：ピグーとコース

### 6-1. ピグー：捨てる費用が安すぎる
食べものを捨てる人は、処理費（税金）や温室効果ガスの費用を **自分ではほとんど払っていません**。これが **負の外部性** です。

$$
\text{社会的費用} = \text{本人が払う費用} + \underbrace{\text{外部費用}}_{\text{処理の税金・環境}}
$$

外部費用が値段に入っていないため、社会全体で見ると **捨てすぎ** になります。
ピグーの解決策は、外部費用の分だけ課税すること（**ピグー税**）です。ゴミ袋の有料化や、事業系ゴミの処理手数料がこれにあたります。ただし、これは **政府が税をかける** やり方です。

### 6-2. コース：取引の手間が小さければ、当事者どうしで解決できる
コースの定理（1960年）はこう言います。**取引の手間（取引費用）が十分小さければ、権利を誰が持っているかに関係なく、当事者どうしの話し合いで効率的な結果にたどりつける。**

食品ロスがこれまで当事者どうしで解決されなかったのは、**取引費用が大きすぎた** からです。
- 余っている人と欲しい人を探す手間
- 値段を決める手間
- 安全かどうかを確かめる手間
- 受け渡しの手間

たべものすべてAIは、この **取引費用をほぼゼロに近づける** ツールです。

> 政府がピグー税をかけなくても、取引費用が下がれば、住民・お店・農家どうしで解決できる。
> これが、**無政府主義的（自律分散）なやり方が経済学的に成り立つ理由** です。

## 7. 公共財と集合行為：オルソンの「選択的誘因」

### 7-1. 需要データは公共財
町全体の「来週買う予定の合計」は、
- **非競合的**：誰かが使っても減らない
- **非排除的**：データを出さなかった人も、ロスの減った町の恩恵を受ける

という意味で **公共財** です。公共財には **ただ乗り（フリーライダー）問題** があります。「自分が出さなくても誰かが出すだろう」とみんなが思うと、誰も出さなくなります。

### 7-2. オルソンの答え：個人にだけ届く得をセットにする
オルソンは『集合行為論』（1965年）で、大きな集団が公共財を作るには、**参加した人にだけ届く個人的な得（選択的誘因）** が必要だと示しました。

たべものすべてAIの構造は、まさにこれです。

| | 公共財（みんなの得） | 選択的誘因（個人の得） |
|---|---|---|
| 内容 | 町・国・世界の食品ロスが減る | 自分の家で買い忘れ・買いすぎ・献立の悩みがなくなる、健康になる、食費が減る |
| 利用者の意識 | 意識しなくていい | **これが使う理由** |

> **人は世界のためではなく、自分の便利さのために使う。その結果として世界が良くなる。**

アダム・スミスの「見えざる手」を、**データの時代に作り直したもの** と言えます。

## 8. メカニズムデザイン：正直に答えるのが得になる仕組み

「来週買う予定」を、人は正直に教えてくれるでしょうか。
メカニズムデザイン（ハーヴィッツ、マスキン、マイヤーソン：2007年ノーベル経済学賞）では、**本当のことを言うのが一番得になる性質** を **誘因両立性** と呼びます。

たべものすべてAIでは、次の理由で正直に答えるのが得になります。

1. **予定は、自分の献立と買い物リストのために使われる**：うそをつくと、自分へのアドバイスが悪くなる
2. **うそをついても得がない**：予定で値段が変わったり、ほかの人より有利になったりしない
3. **罰がない**：予定どおりに買わなくても何も起きない
4. **個人が分からない**：誰の予定かが分からないので、見栄を張る理由がない

$$
\text{正直に答えたときの得} \;\ge\; \text{うそをついたときの得} \quad (\text{どんな状況でも})
$$

この「どんな状況でも正直が一番得」という性質を、**支配戦略での誘因両立性** といいます。

⚠️ 予定を出した人だけに値引きをすると、得をするために予定を水増しする人が出ます。**予定にお金の見返りを直接つけない** ことが大切です（地域ポイントは、ロスを実際に減らしたことに対してつける）。

## 9. 共有資源の統治：オストロムの8原則

オストロム（2009年ノーベル経済学賞）は、漁場・森・水路などの **共有資源** について研究しました。政府が管理しなくても、市場に任せなくても、**地域の人たちが自分たちのルールで長く上手に管理している例が世界中にある** ことを示しました。これは、**無政府主義的な運営が現実に成り立つという実証的な裏づけ** です。

町の食べものとデータを共有資源と考え、オストロムの8つの設計原則をあてはめます。

| オストロムの原則 | たべものすべてAIでの形 |
|---|---|
| ① 境界がはっきりしている | 協同組合の組合員と、対象の地域を決める |
| ② ルールが地域の事情に合っている | 町ごとに、値引きの時間・寄付先・ポイントの使い道を決める |
| ③ ルールを使う人が、ルール作りに参加できる | 1人1票の話し合い |
| ④ 見張り役が、使う人自身か、使う人に責任を持つ | 削減量・基金の使い方をダッシュボードで全員に公開 |
| ⑤ ルール違反には段階的な罰 | 予定の水増し・衛生ルール違反には、注意 → 一時停止 → 退会 |
| ⑥ もめごとを安く早く解決できる | 組合の中に相談窓口 |
| ⑦ 自分たちで決める権利が外から認められている | 行政は「参加者の一人」として尊重する |
| ⑧ 大きな仕組みは、小さな単位の入れ子で作る | 家庭 → 町 → 町どうしの連合 → 国・世界 |

## 10. 行動経済学：人はなぜ買いすぎ、捨てるのか

伝統的な経済学は「人は合理的」と考えます。でも食べものについては、人は **予測どおりに不合理** です。

| 心のくせ（バイアス） | 食べものでの例 | たべものすべてAIでの対策 |
|---|---|---|
| **投影バイアス** | お腹がすいているときに買い物をすると買いすぎる | 「今は空腹なので、予定より多めになっています」と教える |
| **現在バイアス** | 「健康のため」と野菜を買うが、今日はラーメンを食べて野菜が傷む | 買う時点で「今週、本当に食べる予定がありますか」と確認、食べやすいレシピを出す |
| **計画の錯誤** | 「毎日料理する」つもりで買うが、実際はできない | 過去の実績（実際に料理した日数）から現実的な量を出す |
| **限られた注意** | 冷蔵庫の奥のものを忘れる | 期限が近いものから知らせる |
| **まとめ買いの心理会計** | 「お得」だから大容量を買い、使い切れない | 「1個あたりは安いですが、半分捨てると割高です」と計算して見せる |
| **選択肢が多すぎる** | 献立を決められず、結局外食・お惣菜 | 選択肢を3つに絞って提案 |

### ナッジ：強制せず、そっと後押し
セイラーとサンスティーンの **ナッジ**（2017年ノーベル経済学賞はセイラー）は、選ぶ自由を残したまま、良い選択をしやすくする工夫です。
たべものすべてAIは **提案するだけで強制しない** ので、ナッジの考え方そのものです。これは [パレート改善](pareto.md) と [自律分散](decentralized.md) の「強制しない」原則とも一致します。

## 11. 健康経済学：食べものと医療費の外部性

### 11-1. 健康は「自分だけの問題」ではない
日本は国民皆保険なので、一人ひとりの病気の医療費の多くは **みんなの保険料と税金** で払われています（国民医療費は年に40兆円台半ば ※要確認）。
つまり、食生活が悪くて病気になると、その費用の一部はほかの人が負担します。これも **外部性** です。

### 11-2. 内部性
さらに行動経済学では、「将来の自分」に負担を押しつけることを **内部性** と呼びます。今日の自分が好きなものを食べ、将来の自分が病気の費用と苦しみを負う、という構造です。

### 11-3. 食品ロスと健康は同時に良くできる
| | 食品ロス | 健康 |
|---|---|---|
| 原因 | 計画と実際のずれ、忘れ | 計画と実際のずれ（「野菜を食べるつもり」）、知らないこと |
| 解決 | 在庫と期限を知らせ、使い切る献立 | 栄養を知らせ、続けられる献立 |

どちらも原因は **「計画と実際のずれ」と「情報の不足」** なので、同じ仕組みで同時に良くできます。
野菜を「買ったけど食べずに捨てる」をなくすことは、**ロスを減らすことと健康になることが同時に起きる** 典型的な例です。

ただし、[健康の資料](health.md) で決めたとおり、**健康を悪くしてまでロスを減らすことはしない**（優先順位：安全 ＞ 健康 ＞ 好み ＞ ロス ＞ 食費）。

## 12. ネットワーク効果とプラットフォームの独占

### 12-1. 使う人が増えるほど価値が上がる
3章で見たとおり、利用者の割合 $\alpha$ が上がるほど予測が良くなり、ロスが減ります。これは **ネットワーク効果** です。

- 住民が増える → 予測が正確になる → お店が参加したくなる
- お店が増える → 余りの通知・選べる食品が増える → 住民が参加したくなる

住民とお店の両方がいる **両面市場** です。

### 12-2. 危険：一社がすべてを握る
ネットワーク効果が強い市場は、**一つの会社が独り占めしやすい**（勝者総取り）。
食べものと健康のデータを一つの企業が独占すると、次のような危険があります。
- 手数料の値上げ、お店・農家への不利な条件
- データの別の目的への利用
- その会社がやめると、町の仕組みが止まる

### 12-3. 対策：オープンソースと協同組合
| 対策 | 経済学的な意味 |
|---|---|
| オープンソース（MIT） | 誰でも同じ仕組みを作れるので、独占できない（参入障壁をなくす） |
| 共通のデータ形式 | 利用者がほかの運営者に移れる（乗り換えの費用をなくす） |
| 協同組合で運営 | 利用者自身が持ち主なので、利用者から搾り取る理由がない |
| 町ごとの連合 | 一か所が止まっても全体は止まらない |

ネットワーク効果の **得はみんなで分け、独占の害はなくす** 設計です。

## 13. リバウンド効果：効率化が逆効果になるとき

19世紀の経済学者ジェヴォンズは、石炭を効率よく使える蒸気機関ができると、**かえって石炭の使用量が増えた** ことを指摘しました（**ジェヴォンズのパラドックス**）。効率化で使う費用が下がると、使う量が増えることがあります。

食べものでも同じことが起きえます。

| リバウンドの例 | 対策 |
|---|---|
| 余りを安く売れる → お店が仕入れを増やす（3-4節） | 予測を中心に置き、「作った量に対して捨てた割合」で評価 |
| 食費が浮く → その分、余計に食べる・買う → 食べすぎ | 健康を優先する（量と栄養の提案） |
| 食費が浮く → ほかの、環境負荷の高い消費に使う | 浮いたお金を地域ポイントにして、町の中で回す |

**効率化そのものではなく、効率化の後に何が起きるかまで設計する** ことが大切です。

## 14. 世界の食料：センの権原アプローチと、世界規模のパレート改善

### 14-1. 飢えは「食べものが足りない」からではない
センは『貧困と飢饉』（1981年。1998年ノーベル経済学賞）で、ベンガル大飢饉などを分析しました。そして **飢饉は国全体の食べものの量が足りないときではなく、人々が食べものを手に入れる力（権原：エンタイトルメント）を失ったときに起きる** ことを示しました。

> 食べものが世界に十分あっても、お金・仕事・流通・情報がなければ、人は飢える。

したがって「豊かな国の余りを、貧しい国に送ればいい」という単純な話ではありません。

### 14-2. 世界規模で見ると、得をする人と損をする人がいる
豊かな国で食品ロスが減ると、その国の **食べものの需要が減ります**。その結果、世界の穀物などの **値段が下がる** 可能性があります。

| 立場 | 値段が下がると |
|---|---|
| 食べものを **買う側** の貧しい人（都市の貧困層など） | 得をする（食べものが手に入りやすくなる） |
| 食べものを **売る側** の貧しい人（途上国の小さな農家） | 損をするおそれがある（収入が減る） |

つまり、世界規模では **単純なパレート改善にはならない可能性** があります。正直に書いておくべき点です。

### 14-3. 世界規模のパレート改善に近づけるには
| 方法 | 内容 |
|---|---|
| ① 損失の場所に合わせる | 豊かな国のロスは **川下**（家庭・お店）。途上国のロスは **川上**（収穫後の保存・冷蔵・輸送）が中心。途上国版では、たべものすべてAIの予測を **農家の保存・出荷のタイミング** に使い、農家の収入を増やす |
| ② 需要の見通しを農家に開く | 世界の需要の見通しを小さな農家にも公開する。大きな商社だけが情報を持つ非対称性をなくす |
| ③ 浮いたお金を回す | 豊かな国で浮いた食費・処理費の一部を、途上国の保存設備（冷蔵・乾燥）に回す（世界版の「たべものすべて基金」） |
| ④ 土地と資源の余裕 | ロスが減れば、同じ食べものを作るのに必要な土地・水・肥料が減る。森林破壊・水不足の圧力が下がり、将来の世代が得をする |

### 14-4. 人類の未来との関係
世界の人口は2050年に約97億人に達すると見込まれており、食べものの生産を大きく増やす必要があると言われています（※要確認）。
しかし、**捨てている分を減らすことは、畑を増やさずに食べものを増やすこと** と同じです。

$$
\text{実質的な食べものの供給} = \text{生産量} \times (1 - \text{ロス率})
$$

ロス率を下げることは、**新しい土地・水・エネルギーを使わない「見えない増産」** です。これは、人類が地球の限界の中で生きていくための、最も安くて速い方法の一つです。

## 15. まとめ：なぜ全世界が得をしうるのか

| 経済学の考え方 | たべものすべてAIでの意味 |
|---|---|
| **死荷重**（厚生経済学） | 食品ロスは消えている価値。取り戻せば分け合える ＝ パレート改善の余地 |
| **新聞売り子モデル**（在庫理論） | 廃棄は予測のばらつき $\sigma$ に比例。情報で $\sigma$ を下げれば廃棄が減る |
| **ブルウィップ効果** | 買う前の需要を共有すれば、農家の作りすぎまで減る |
| **ハイエク** | 散らばった知識を、中央計画なしでまとめる信号（値段＋合計数） |
| **アカロフ** | 期限が近い食品の不安を、情報でなくす |
| **コース** | 取引費用を下げれば、政府なしで当事者どうしが解決できる |
| **オルソン** | 個人の便利さ（選択的誘因）が、公共財（世界のロス削減）を生む |
| **メカニズムデザイン** | 正直に答えるのが一番得になる仕組み |
| **オストロム** | 地域の人たちが自分たちのルールで共有資源を管理できる |
| **行動経済学・ナッジ** | 強制せず、人の心のくせに合わせて後押しする |
| **健康経済学** | ロスと健康は同じ原因。同時に良くなる |
| **ネットワーク効果** | 使う人が増えるほど良くなる。独占はオープンソースと協同組合で防ぐ |
| **ジェヴォンズ** | 効率化の後に何が起きるかまで設計する |
| **セン** | 世界規模では損をする人もいる。だから途上国の農家の側にも得を回す |

> **一人ひとりは、自分のために「無駄にならない・おいしい・健康に良い」食べ方を選ぶだけ。**
> **その選択が、誰の分か分からない薄い信号として集まると、取引の手間が消える。**
> **そして、政府の計画なしに、町・国・世界の食べものが最適に近づいていく。**
>
> **食品ロスは、人類がテーブルの上に置き忘れている巨大な取り分である。**
> **たべものすべてAIは、それを全員で分け合うための仕組みである。**
