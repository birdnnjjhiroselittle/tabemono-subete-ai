# 健康：食品ロスと健康を同時に良くする

たべものすべてAIは、食品ロスを減らすだけでなく、**一人ひとりの健康** も一緒に考えます。

---

## 1. なぜ難しいのか：役所の縦割り

食べものと健康は、日本ではいくつもの役所に分かれています。

| 分野 | おもな担当 |
|---|---|
| 健康・栄養（日本人の食事摂取基準、健診） | 厚生労働省 |
| 生産・農業・食育 | 農林水産省 |
| 食品ロス削減・食品表示・食品衛生の基準 | 消費者庁 |
| ゴミ・リサイクル | 環境省・市町村 |

「町の人に足りない栄養に合わせて、地元の農家が作るものを変える」といったことは、役所をまたぐのでなかなか進みません。

**たべものすべてAIは、役所どうしの調整を待ちません。** 一人ひとりと町の人どうしがデータでつながり、下から（ボトムアップで）つなげます。くわしくは [自律分散の運営](decentralized.md)。

---

## 2. 個人の健康で使う情報

| 情報 | 取り方 | 使い方 |
|---|---|---|
| アレルギー | 本人が登録 | **絶対に提案しない**（最優先） |
| 持病・食事の制限（塩分・糖質など） | 本人が登録、医師や栄養士の指示を入力 | 献立の上限として守る |
| 体重・血圧 | 体重計・血圧計の表示をカメラで読む（「どこだっけAI」の機能） | 変化に合わせて献立を調整 |
| 歩数・睡眠 | スマートウォッチなど | 使ったエネルギーに合わせて量を調整 |
| 健診の結果 | 本人が写真で読み込む | 気をつけたい栄養を知る |
| 食べたもの | 在庫の減り方、食事の写真 | 栄養のかたよりに気づく |

基準には、国が公開している **日本人の食事摂取基準** などの公開データを使います（誰でも使えるデータなので、許可を待つ必要はありません）。

## 3. 健康と食品ロスがぶつかるとき

「期限が近いから揚げ物を食べましょう」では本末転倒です。そこで **優先順位** を決めます。

```
① 安全（アレルギー・食中毒）  ← 絶対に守る
② 健康（持病の制限・栄養）    ← 悪くしない
③ 好み・食べたい気持ち
④ 食品ロスを減らす
⑤ 食費を減らす
```

> **健康を悪くしてまで食品ロスを減らさない。** これは本人の健康についてのパレート改善の約束です（→ [パレート改善の設計](pareto.md)）。

### 例
- 期限が近い食パンが残っている → 「ジャムではなく、卵と野菜のサンドイッチ」にする
- 余った揚げ物のお惣菜 → 健康上の制限がある人には勧めず、制限のない家族や近所の人へ回す
- 塩分を控えている人 → 値引きの漬物ではなく、値引きの野菜で献立を作る

---

## 4. 健康 × 食品ロス × 農業を下からつなぐ

```
一人ひとり：「鉄分が足りない」「野菜が足りない」
      ↓ 個人が分からない形でまとめる（本人の同意がある分だけ）
町：「この町では緑の野菜が足りていない人が多い」
      ↓
地元の農家・お店：作るもの・仕入れるものを変える
      ↓
町の人の健康が良くなる ＋ 売れ残りが減る ＋ 農家の売上が増える
```

役所をまたぐ調整を、**住民・農家・お店が直接データでつながる** ことで実現します。

---

## 5. 守ること（法律と安全）

自律分散で進めますが、**人の命と健康に関わる法律は守ります**。

| 守ること | 内容 |
|---|---|
| 診断しない | 病気の診断・治療はしない（医師の仕事）。気になる変化は「お医者さんに相談しては」と伝えるだけ |
| 病歴は特に慎重に扱う | 病歴などは、個人情報保護法で特に配慮が必要な情報とされている。本人の同意なしに集めない、端末の外に出さない |
| 効果をうたわない | 「この献立で病気が治る」とは言わない |
| 食品の受け渡しの衛生 | 余った食品を回すときは、衛生のルールとガイドラインに従う |
| 医師・栄養士の指示が優先 | AIの提案より、専門家の指示を上に置く |
