# 家の食べもの見守りとコントロール

冷蔵庫・パントリー（食品庫）・キッチンに置いた野菜などを見守り、**気温** と **食べる人の需要** を考えて、

- **いつ食べるか**（どれから使うか）
- **どこに置くか**（常温・野菜室・冷蔵・冷凍）
- **どう変えるか**（下ごしらえ・作り置き・冷凍・おすそ分け）
- **いつ・どれだけ買うか**

を毎日コントロールする仕組みです。

> 約束はこれまでと同じ **「見るだけ・教えるだけ」**。AIが勝手に捨てたり買ったりはしません。決めるのは人です（→ [プライバシー](privacy.md)）。

---

## 1. 全体の流れ：見守る → 予測する → 決める → 伝える

```
 ┌─────────── 見守る（センシング） ───────────┐
 │ 冷蔵庫・パントリー・キッチンの在庫と状態    │
 │ 置き場所ごとの温度・湿度、外の気温と天気予報  │
 │ 家族の予定・体調・食べたい気持ち・健康目標    │
 └──────────────────┬──────────────────┘
                    ▼
 ┌─────────── 予測する ───────────┐
 │ 食材ごとの「あと何日おいしいか」   │ ← 温度で傷む速さが変わる
 │ この先数日、誰が何食たべるか       │ ← 予定・季節・天気で変わる
 └──────────────────┬──────────────────┘
                    ▼
 ┌─────────── 決める（最適化） ───────────┐
 │ 捨てる量が最小、健康が最良になる          │
 │ 「食べる順・置き場所・買う量」を組む       │
 └──────────────────┬──────────────────┘
                    ▼
 ┌─────────── 伝える ───────────┐
 │ 🎧「トマトは今日の夕食に。         │
 │     バナナは冷蔵庫に入れないで」   │
 └──────────────────┬──────────────────┘
                    ▼
       食べた・使った・捨てた → 予測を学び直す（毎日くり返す）
```

## 2. 見守る：何を測るか

| 場所 | 見るもの | 測り方 |
|---|---|---|
| **冷蔵庫** | 何が・どの段に・いくつ、庫内の温度 | 扉を開けたときの撮影、温度センサー |
| **野菜室** | 葉物のしおれ、変色 | 扉を開けたときの撮影、湿度センサー |
| **冷凍庫** | 冷凍した日、量 | 冷凍時の声・撮影（「カレー2食分冷凍」） |
| **パントリー** | 乾物・缶詰・レトルト・米、期限 | 棚のカメラ、重さを測るマット |
| **キッチンの常温置き** | 玉ねぎ・じゃがいも・バナナ・トマトなど、芽・熟れ具合 | 固定カメラ、ARグラス・イヤホンのカメラ |
| **部屋と外の環境** | 室温・湿度、今日〜来週の気温・天気 | 温湿度センサー、天気予報 |
| **食べる人** | 予定（外食・出張・来客）、体調、食べたい物、健康目標 | 家族の予定表、声、本人の登録 |

映像は端末の中で「トマト 3個 キッチン常温 熟れ具合：食べごろ」のような文字に変えて、すぐに消します。

## 3. 予測①：気温で「あと何日」が変わる

食べものが傷む速さは温度で大きく変わります。目安として **温度が10℃上がると、傷む速さは2〜3倍** になります（Q10＝2〜3）。

```
あと何日 ＝ 基準の日数 ÷ 温度による速さの倍率 − ここまでの劣化
温度による速さの倍率 ≒ Q10 ^ ((今の温度 − 基準温度) ÷ 10)
```

### 例：キッチンの常温に置いたトマト

| 室温 | 速さの倍率（Q10=2.5として） | 食べごろが続く目安 |
|---|---|---|
| 15℃（春・秋） | 1倍 | 約6日 |
| 25℃（初夏） | 約2.5倍 | 約2〜3日 |
| 30℃（真夏・エアコンなし） | 約4倍 | 約1〜2日 |

- 毎日の **実際の室温の記録** と **天気予報** を使い、「あと何日」をその都度計算し直す
- カメラで見た色・しわ・斑点で、計算を補正する
- 同じ食材でも、家ごと・季節ごとに学習して精度を上げる

### 置き場所の向き・不向き（温度の注意）

| 食材 | よい置き場所 | 気をつけること |
|---|---|---|
| 葉物（ほうれん草など） | 冷蔵・野菜室、湿らせて立てる | 乾燥としおれ |
| トマト | 熟すまで常温、熟れたら冷蔵 | 夏の常温は早く傷む |
| バナナ・さつまいも | 常温（涼しい所） | 冷やしすぎると低温障害で黒くなる |
| 玉ねぎ・じゃがいも | 風通しのよい冷暗所 | 夏は芽・腐敗が早い。じゃがいもの芽は取り除く |
| 肉・魚 | 冷蔵（チルド）、使わないなら早めに冷凍 | 期限を優先。画像判定は補助だけ |

## 4. 予測②：食べる人の「需要」を読む

在庫がいくらあっても、**食べる人がいなければロス** になります。

| 需要を変えるもの | 例 | 反映のしかた |
|---|---|---|
| 予定 | 父が出張で3日いない、週末に来客 | 食べる人数・食数を数え直す |
| 気温・天気 | 暑い日は冷たい物・さっぱりした物、寒い日は鍋 | 「食べたくなる料理」の確率を変える |
| 体調・食欲 | 子どもが風邪で食欲がない | 量を減らし、消化のよい料理に |
| 健康目標 | 減塩中、たんぱく質を増やしたい | 献立の上限・下限として守る |
| 好み・飽き | 3日続けてカレーは嫌 | 同じ料理が続かないようにする |
| 習慣 | 金曜はいつも外食 | 過去の記録から学ぶ |

```
この先の需要 ＝ 誰が（人数） × 何食（予定） × 何を食べたいか（気温・好み・体調・健康目標）
```

## 5. 決める：4つのコントロール

供給（在庫と「あと何日」）と需要（食べる人と食数）を突き合わせ、ずれを4つの手段で埋めます。

### ① 食べる順（期限が近い物から先に）
- 「あと何日」が短い順に献立へ入れる（先に期限が来る物から使う＝FEFO）
- ただし優先順位は **安全 > 健康 > 好み > 食品ロス > 食費** のまま

### ② 置き場所を変える
- 「明日から30℃の予報。キッチンのトマトとじゃがいもは野菜室へ」
- 「熟れたアボカドは冷蔵庫へ。熟れていない物は常温のまま」

### ③ 形を変える（間に合わないときの延命）
- 食べきれない葉物 → ゆでて冷凍
- 熟れすぎたバナナ → 冷凍してスムージー用に
- 予定が変わって余るおかず → 作り置き・冷凍・近所へおすそ分け（→ 町の仕組みへ）

### ④ 買う量とタイミング
- 「この先の需要 − 今の在庫 − 傷んで使えなくなる見込み」だけを買う
- 暑い時期は **少なく・こまめに**、涼しい時期はまとめ買い
- 買い物リストを、スーパーでイヤホン・ARグラスから声で伝える

### 1日の例（夏）

> 🌡️ 予報：明日 32℃　👨 父：明日から出張で2泊　🧒 子ども：部活で帰りが遅い
>
> 🎧「明日は暑くなります。キッチンのトマトとじゃがいもは野菜室へ移しましょう」
> 🎧「お父さんがいないので、明日の鶏むね肉は半分を冷凍しておきましょう」
> 🎧「今夜はほうれん草とトマトの冷製パスタはどうですか。野菜が200gとれて、両方使い切れます」
> 🎧「週末まで牛乳は1本で足ります。今日は買わなくて大丈夫です」

## 6. 学び直す（フィードバック）

- 「食べた」「使った」「捨てた」を記録（声、在庫の減り方、ゴミ箱のはかり）
- 予測と実際の差から、家ごとの「傷む速さ」と「食べる量」を学び直す
- 捨てた理由（傷んだ・食べる人がいなかった・まずかった）を分けて記録し、次の提案を変える
- 学習は端末の中で行う（連合学習）。町へは、誰の分か分からない合計の数字だけを送る

---

## 7. 家の外へつなぐ

家の中で予測した **「この先食べる量」と「余りそうな物」** を、個人が分からない形でまとめると、

- お店：明日の仕入れ量の予測が正確になる（作りすぎ・仕入れすぎが減る）
- 近所：余りそうな物を早めに知らせて、おすそ分け・子ども食堂へ
- 農家：町全体の需要と、気温による需要の変化を事前に知る

→ くわしくは [企画書](proposal.md)・[経済学](economics.md)・[自律分散](decentralized.md)

---

## 8. 守ること

- **鮮度は「目安」**。食べられると断定しない。肉・魚・乳製品は期限を優先し、においや見た目の最終確認を促す
- **強制しない**。提案するだけで、家族の誰も従う必要はない
- **映像は保存しない**。家族の顔や会話は記録しない
- 家電（冷蔵庫の温度設定など）を自動で動かすのは、本人が明示的に許可した場合だけ

## 9. 段階的な実現

| 段階 | 内容 | 必要なもの |
|---|---|---|
| 1 | スマホで在庫登録、天気予報と室温で「あと何日」を計算して通知 | スマホ、温湿度センサー（安価） |
| 2 | 冷蔵庫・パントリーのカメラで在庫を自動把握、家族の予定表と連携 | 庫内カメラ、カレンダー連携 |
| 3 | 置き場所・形・買う量まで含めた毎日の提案、学び直し | 予測モデル、ゴミ箱のはかり |
| 4 | イヤホン・ARグラスで声と表示の案内、町への需要共有 | ウェアラブル、連合学習 |
