# パレート改善の設計：「誰も損をしない」食品ロス削減

たべものすべてAIは、**社会全体の得を大きくする（功利主義的な目標）** ことを目指します。
ただし、そのやり方は **「誰も損をせず、誰かが得をする」＝パレート改善** になるように作ります。

---

## 1. パレート改善とは

| 用語 | 意味 |
|---|---|
| **パレート改善** | 誰の状態も悪くせずに、少なくとも1人の状態を良くする変化 |
| **パレート最適** | これ以上、誰かを損させずに誰かを得させることができない状態 |
| **カルドア・ヒックス基準** | 得をした人の得が、損をした人の損より大きければ良しとする考え方（損をした人に実際に補償するとは限らない） |

功利主義をそのまま突き詰めると、**「全体の得のためなら一部の人が損をしても構わない」** という結論になりがちです。
たとえば「ロスを減らせるなら、全家庭の冷蔵庫を強制的に監視すればいい」という考え方です。

たべものすべてAIはそうしません。**損が出そうな人には、得の一部を回して損を埋めます（補償）。** そうすることで、カルドア・ヒックス基準の改善を、本当のパレート改善に近づけます。

### なぜパレート改善にこだわるのか
- **反対する人がいなくなる**：自治体・お店・住民の合意が取りやすい
- **続けられる**：損をする人がいる仕組みは、いずれ反対されて止まる
- **信頼される**：「ロス削減」の名目で誰かに我慢を押しつけない

---

## 2. 食品ロスは「捨てられている得」

食品ロスとは、**お金・手間・エネルギーをかけて作ったのに、誰も食べずに捨てられたもの** です。
捨てている分を減らせば、その価値を参加者で分け合えます。だから、パレート改善を作りやすい分野です。

```
今：     作る → 運ぶ → 売る → 【捨てる：お金を払って燃やす】
これから： 作る量が適切になる → 余りは食べる人に届く → 捨てる費用が減る
                     ↓
          浮いたお金・食べもの・時間を、参加者で分ける
```

---

## 3. 関係者ごとの「得」と「損」のチェック表

| 関係者 | 得 | 損が出る可能性 | 損をなくす仕組み |
|---|---|---|---|
| **家庭** | 買い忘れ・買いすぎが減る、食費が減る、献立に迷わない | 食べたいものを我慢させられる／プライバシー | AIは **提案するだけで強制しない**。データは本人の同意制で、家族それぞれがオン・オフを選べる。映像は保存しない |
| **お店** | 廃棄の費用が減る、仕入れが正確になる、新しいお客さん | 値引き品が売れて、定価の商品が売れにくくなる | 値引きは閉店前・数量限定に。予測で **作る量が減る** ので、売上が少し減っても **利益は増える** ように設計する |
| **農家** | 規格外の作物が売れる、需要の見通しで作付けしやすい | 需要が見えることで、買いたたかれる | 需要の見通しは農家にも同じように公開する。最低価格のルールを作る |
| **食品メーカー** | 返品・在庫の廃棄が減る、需要データが手に入る | 作りすぎが減るぶん、出荷量が減る | 売上より **利益** で評価する（廃棄・返品の費用が減るため）。データ提供で新しい収入 |
| **ゴミ処理・回収の業者** | — | 処理する量が減って、仕事が減る | **堆肥化・飼料化・回収ルートの運営** を新しい仕事として任せる |
| **子ども食堂・フードバンク** | 食材が安定して手に入る | 質の悪いものを押しつけられる | 受け取るかどうかを選べる。衛生のガイドラインを守る |
| **自治体** | ゴミ処理費が減る、食品ロス削減の計画が進む、福祉が充実する | 運営の費用がかかる | **ゴミ処理費が減った分の一部で運営する**（成果に応じて払う方式） |
| **環境・将来の世代** | CO₂が減る、資源のムダが減る | — | — |

## 4. 得を分け合う仕組み（補償の流れ）

```
     【食品ロスが減って浮いたお金】
       ・自治体：ゴミ処理費の削減分
       ・お店：廃棄費用の削減分
       ・メーカー：返品・在庫廃棄の削減分
                 ↓ 一部を出し合う
          【たべものすべて基金（仮）】
                 ↓
  ┌────────────┼────────────┐
  住民：地域ポイント   お店：認定・手数料割引   業者：堆肥化の委託費
 （データの提供・      （定価の売上が減った   （処理量が減った分を
   余りを買った分）      分の穴埋め）          新しい仕事で）
```

- 地域ポイントは **町の中のお店でしか使えない** ようにする。浮いたお金が町の外に出ていかず、町の中で回る。
- 分ける割合は、実証で各関係者の得と損を測ってから決める。

## 5. 「強制しない」ことがパレート改善の条件

パレート改善を守るために、次のことはしません。

| しないこと | 理由 |
|---|---|
| 参加を義務にする | 参加したくない人に損をさせないため（**オプトイン**＝自分で選んで参加する形） |
| AIの提案に従わせる | 「好きなものを食べる自由」も大事な得だから |
| 個人の食事データを本人の同意なく使う・売る | プライバシーの損をなくすため |
| 損をした人を放っておく | パレート改善でなくなるため |

> **自分で選んで参加した人は、誰も損をしない。参加していない人も、今より悪くはならない。**
> これがたべものすべてAIの約束です。

---

## 6. 測り方：本当に誰も損をしていないか

功利主義的な目標は「全体の合計」だけを見がちです。この企画では、**関係者ごとに** 得と損を測ります。

| 関係者 | 測るもの |
|---|---|
| 家庭 | 食費、捨てた量、満足度（「おいしい」「食べたいものが食べられた」） |
| お店 | 売上、**利益**、廃棄量、定価の商品の売れ行き |
| 農家 | 規格外品の売上、取引価格 |
| 業者 | 処理量の変化と、新しい仕事の収入 |
| 自治体 | ゴミ処理費、運営費、住民の参加率 |
| 子ども食堂 | 受け取った量、使えた割合 |

**ルール：段階ごとに見直して、損をしている関係者が1つでも見つかったら、次の段階に進む前に設計を直す。**

---

## 7. 正直な限界

- 社会全体で **厳密に** 誰も損をしない変化は、現実にはほとんどありません。
- この企画が目指すのは、**「参加した人は誰も損をしない」＋「損が出そうな相手には得の一部を回す」** という、実際に運用できるパレート改善です。
- 何を「得」とするか（お金・時間・満足・環境）は人によって違います。だから、関係者と話し合って決めます。

---

## 8. ほかの倫理の考え方との関係

| 考え方 | この企画での形 |
|---|---|
| 功利主義（最大多数の最大幸福） | 目標：社会全体の食品ロスを減らす |
| パレート改善 | やり方：誰も損をさせない、損が出そうなら補償する |
| 義務論（カント） | 同意なしに人をデータの材料にしない |
| ロールズの正義論 | 余りは子ども食堂・生活に困っている人へ優先して届ける |
| 共同体主義 | 地域ポイントで、町の中で回す |
| 徳倫理 | 「もったいない」「売り切れ御免を良いことにする」文化 |

> **一言でいえば、「ルールで守られた功利主義」。**
