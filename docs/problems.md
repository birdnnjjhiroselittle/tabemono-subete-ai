# 問題の大きさ：食品ロスと健康

たべものすべてAIが取り組む2つの問題、**食品ロス** と **食生活に由来する病気** が、日本とアメリカでどれくらい大きいかをまとめます。
数値は2026年11月時点で確認した公表資料・報道によります（出典は末尾）。

---

## 1. 食品ロス：いちばん捨てているのは家庭

| | 日本 | アメリカ |
|---|---|---|
| 年間の食品ロス | **461万トン**（2024年度推計） | 余剰食品 **7,000万トン**（2024年、食料供給の約29%） |
| うち家庭 | **233万トン**（約半分、2023年度） | **最大の発生源**（全体の約35%） |
| お金に換算 | 経済損失 **3.8兆円**、1人あたり年 **約3.1万円**（2024年度） | 余剰食品の価値 **約3,820億ドル**（2023年） |
| 環境負荷 | 温室効果ガス **978万t-CO2**（2024年度） | 余剰食品のうち寄付は3%未満、約85%が廃棄 |

### 日本の推移

| 年度 | 全体 | 事業系 | 家庭系 |
|---|---|---|---|
| 2021 | 523万トン | 279万トン | 244万トン |
| 2022 | 472万トン | 236万トン | 236万トン |
| 2023 | 464万トン | 231万トン | 233万トン |
| 2024 | 461万トン | — | — |

- 家庭系の国の目標：2000年度（433万トン）比で **2030年度までに半減＝216万トン**。2023年度は233万トンで、あと17万トン
- 事業系の目標：2000年度（547万トン）比で2030年度までに60%削減＝219万トン

### アメリカの動き

- 2024年の減少（約2.2%）は、ほとんどが **家庭での削減（約95万トン）** によるもの
- **家庭が変われば、国全体の数字が動く** ことを示している

### 家庭で捨てる理由は「情報の問題」

- 冷蔵庫やパントリーの奥で **忘れていた**
- **あるのにまた買った**（二重買い）
- 暑さや保存場所のせいで **思ったより早く傷んだ**
- 家族の予定が変わって **食べる人がいなかった**
- 何を作ればいいか **思いつかなかった**

これらは、見守って、予測して、教えるAIが最も得意な分野です → [家の食べもの見守りとコントロール](home-control.md)

## 2. 健康：食生活に由来する病気が医療費を押し上げている

| | 日本 | アメリカ |
|---|---|---|
| 医療費 | 国民医療費 **48.1兆円**（2023年度・過去最高、GDP比約8%） | 年間医療費 **4.9兆ドル**。その約90%が慢性疾患・精神疾患のある人に |
| 糖尿病 | 「強く疑われる者」約 **1,000万人**、「可能性を否定できない者」約 **1,000万人**（2016年調査） | 糖尿病 **3,800万人超**、予備群 **約9,800万人** |
| 肥満 | — | 成人の肥満率 **約40%**（関連医療費 年約1,730億ドル） |
| 食習慣 | 野菜 **256g/日**（目標350g）、食塩 **9.8g/日**（目標7g）（2023年） | — |

- 日本人は、野菜が毎日 **約100g足りず**、塩を **約3g多く** 摂っている
- 医療費は毎年過去最高を更新し、その大きな部分を糖尿病・高血圧などの生活習慣病が占める

---

## 3. 2つの問題は、同じ冷蔵庫の中にある

```
冷蔵庫の奥で野菜が傷む  →  捨てる（食品ロス）
            ＋
野菜が足りず、手軽な加工食品で済ませる  →  塩分・糖質が多くなる（健康）
```

**「家にある物で、体に良い物を、無駄なく」** を毎日自然にできれば、食品ロスと生活習慣病の両方に効きます。
ただし優先順位は変えません。**健康を悪くしてまで食品ロスを減らさない**（→ [健康](health.md)）。
