# 備蓄と買い物の全体最適

**はしごで10円を追うより、備蓄と共同購入とAIの計算で、町全体の値段そのものを下げる。**

政府が呼びかける家庭の食料備蓄を、食品ロスを出さずに、楽しく、安く、町全体で最適に行う仕組みです。

---

## 1. 政府が呼びかけている家庭の備蓄

農林水産省の目安は **1人あたり最低3日分〜1週間分** です。災害でライフラインが1週間以上止まった例や、支援物資が3日以上届かなかった例が多いことが理由です。

| 品目 | 目安 | 大人2人・1週間の例 |
|---|---|---|
| **水** | 1人1日 約3L（飲み水＋調理用） | 約42L（2Lボトル6本入り×4箱） |
| **主食** | 米・乾麺・パン・シリアルなど | 米なら1食約75g（乾燥時）として約3kg（概算） |
| **主菜** | 缶詰（魚・肉）、レトルト食品、豆 | 1人1日1〜2品 |
| **野菜・果物** | 日持ちする野菜、野菜ジュース、ドライフルーツ | 野菜不足になりやすいので意識して入れる |
| **熱源** | カセットコンロとボンベ | 調理の回数から計算する |
| **家族ごとの物** | 乳児のミルク、高齢者のやわらかい食べ物、アレルギー対応の食品 | 店で最も手に入りにくいので最優先 |

### ローリングストック
普段の食品を少し多めに買い置きし、**期限の近い物から食べて、食べた分だけ買い足す** 方法です。
備蓄品が期限切れで捨てられるのを防ぐので、**食品ロス対策そのもの** でもあります。たべものすべてAIの [家の食べもの見守りとコントロール](home-control.md) は、ローリングストックを自動で回す仕組みとして使えます。

### 国の備蓄との関係
- 2025年4月に **食料供給困難事態対策法** が施行され、食料の供給が大きく減るおそれがある段階から政府が対策本部を置く仕組みができました
- 国は、民間の在庫も含めた「官民合わせた備蓄」として全体をとらえる方針です
- 家庭の備蓄は、その **いちばん手前の層** にあたります

---

## 2. 備蓄の落とし穴：買い占めは共有地の悲劇

2024〜25年の米不足では、多くの人が一度に買ったことで品薄が悪化しました。

- 一人ひとりにとっては「今のうちに買う」が合理的
- しかし全員がそうすると、品薄と値上がりがひどくなり、全員が損をする

これは [共有地の悲劇](https://github.com/birdnnjjhiroselittle/earth-table/blob/main/docs/local-units.md) と同じ構造です。だから備蓄は **「少しずつ・余っている時に・上限まで」** 集める必要があります。

---

## 3. はしごの買い物は、全体で見ると損

### 例：10円安い卵を求めて隣の店まで車で行く

| | 金額の目安 |
|---|---|
| 安くなる分 | 100〜200円 |
| 余分に走る5kmのガソリン | 約70円 |
| かかる時間30分（時給1,000円で換算） | 約500円 |
| CO2・渋滞・駐車場の混雑 | みんなで負担 |

自分の時間を入れると多くの場合は損で、社会全体ではさらに損です。それでもはしごをするのは、

- 値段の **情報がばらばら** で、比べないと分からない
- 比べて安く手に入れることが **楽しい**（狩り・採集の本能に近い）

からです。

---

## 4. 全体最適の答え

### ① AIが「その家庭にとっての本当の安さ」を計算する

```
本当の費用 ＝ 値段 ＋ 移動費 ＋ 時間の価値 ＋ 傷んで捨てるリスク
条件：      備蓄が目標の日数を下回らない、健康・アレルギーの条件を守る
```

$$
\min_{\text{どこで・いつ・何を・いくつ}} \;
\sum (\text{値段} + \text{移動費} + \text{時間の価値} + \text{廃棄リスク})
\quad \text{s.t.}\quad \text{備蓄日数} \ge D_{\text{目標}}
$$

- 普段の通勤路・送り迎えの途中にある **1〜2店で済ませるのが最適** という答えになることが多い
- 🎧「今週はA店で卵と牛乳。B店には行かなくて大丈夫です（差は30円）」
- 比べる手間はAIに任せ、人は結果だけ受け取る

### ② 備蓄が「安い時に買う」余裕をつくる

1〜2週間分の備蓄があれば、

- 毎日の特売を追わなくても、**本当に安い時（旬・余り）にまとめて買える**
- 高い時・品薄の時は **家の備蓄を食べてやり過ごせる**

備蓄は、災害への備えであると同時に、**家庭の値段変動のクッション** になります。
町の多くの家庭がこう動けば、品薄の時に店へ人が殺到しなくなり、**町全体の値段変動も小さく** なります。

### ③ 個人で比べるより、町でまとめる

| 仕組み | 効果 |
|---|---|
| 家庭の「来週買う予定」の合計をお店へ | 仕入れが正確になり、廃棄が減る。今は廃棄の費用が値段に上乗せされているので、**値段そのものが下がる** |
| 近所の共同購入・共同配送 | 各家庭が車で往復する代わりに、トラック1台で配る。ガソリン・時間・CO2が大幅に減る |
| 受け取り場所（ピックアップ） | 駅・学校・公民館などで受け取り、ついでに持ち帰る |
| 備蓄品の町での見える化 | 町全体の備蓄日数（誰の分か分からない合計）を共有し、足りない品目だけ計画的に仕入れる |

### ④ 影の価格で「いつ買うか」をそろえる

[統合最適化](integrated-optimization.md) の影の価格を、備蓄にも使います。

- 余っている物・旬の物（影の価格が低い）→ 「今が備蓄の買い時です」
- 品薄の物（影の価格が高い）→ 「今は買わず、家の分を食べましょう」

一人ひとりが自分の得を考えて動くだけで、町全体として **余っている時に備え、足りない時に使う** 動きになります。

## 5. ゲームにする：「そなえの森」（仮）

**家の備蓄＝「あと何日生き延びられるか」のゲージ** にします。

| ゲームの要素 | 現実で起きていること |
|---|---|
| **サバイバル日数のゲージ** | 家の在庫と家族の人数から、カロリー・水・たんぱく質が何日分あるかを自動で計算（目標3日 → 7日） |
| **循環ボーナス** | 期限の近い物を食べて買い足すと森が育つ。期限切れで捨てると枯れる |
| **備蓄ごはんの日**（月1回） | 「今日は停電の想定。備蓄だけで夕食を」のチャレンジ。おいしく作れたらレシピを共有 |
| **家族の装備** | 赤ちゃん・高齢者・アレルギーの人の分がそろうと「家族の守り」が完成 |
| **町の森** | 町全体のサバイバル日数の合計を共有。町の目標を達成すると町の木が実る |
| **お得の狩り** | はしごの代わりに、AIが出す「余っている物を救う・旬を備蓄する」クエストで、安さを追う楽しさを満たす |

### ルール：「買い占めは負け」

- **少しずつ集めると高得点**：1週間で集めるより、1〜2か月かけて少しずつそろえる方が高い
- **余っている物・旬の物は得点2倍**（影の価格が低い物）
- **品薄の時に買うと減点**。その時期に家の備蓄から食べるとボーナス
- **目標は1〜2週間分まで**。それ以上ためても得点は増えない

---

## 6. 全部つなげると

```
家の在庫（見守り）＋ 備蓄の目標（政府の目安）＋ 家族の健康
    ↓
AIが「何を・いつ・どの店で・どれだけ」買うかを計算（本当の費用が最小）
    ↓
町の合計で、お店の仕入れと共同配送を最適化（影の価格で買う時期をそろえる）
    ↓
ゲーム「そなえの森」：サバイバル日数・循環ボーナス・買い占めは負け
    ↓
災害に強い ＋ 食品ロスが減る ＋ 安い ＋ 時間とCO2が浮く ＋ 品薄でも慌てない
```

---

## 7. 守ること

- **不安をあおらない**：「足りないかも」で買わせる表現はしない。備蓄は落ち着いて少しずつ
- **値段の情報は正確に**：お店の値段データは、お店の同意のもとで使う
- **お店を損させない**：共同購入・予測で、お店の利益が減らないように設計する（→ [パレート改善](pareto.md)）
- **困っている人を置き去りにしない**：備蓄を買う余裕がない家庭には、町の備蓄・フードバンクとつなぐ
- **最終判断は人**：AIは計算して提案するだけ
